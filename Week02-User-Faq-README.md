FAQ 1 - Settings - Accessibility

# How to change cursor pointer size

User goal: Change cursor size per personal preferences and visibility needs.

Tool path tested: Settings - Accessibility - Mouse cursor and touch

Steps:
1. Open settings - windows start navigation or Win + I shortcut
2. Select - Accessibility
3. Select - Mouse pointer and touch
4. Select cursor size
5. Adjust size using slider

Escalate - If cursor change causes display issues, collect evidence and escalate to hardware/ desktop support.


FAQ 2 - Task Manager

# How to force close a frozen or not responding application

User goal: Force close an application that has stop responding or frozen.

Tool path tested: Task Manager - Identify app - Close / End task

Steps:
1. Open task manager using shortcut Ctrl + Shift + Esc
2. Locate app that is frozen / not responding
3. Click on app to highlight
4. Click "end task"
5. Confirm app closes and disappears from "processes" window

Escalate - If task manager becomes unresponsive, crashes, or fails to launch, collect evidence and escalate senior technician.


FAQ 3 - Control Panel

# How do I change internet adapter settings in control panel?

User goal: Diagnose connectivity issues or disable adapter settings

Tool path tested: Windows search - Control panel - network and internet - change adapter settings

Steps:
1. Search "Control Panel" using Windows search
2. Open Control panel
3. Select "network and internet"
4. Select "change adapter settings"
5. Select desired internet adapter
6. If disabling, select "disable"
7. If diagnosing, select "diagnose" and follow diagnostic prompts

Escalate - If having connectivity issues, and they persist after network diagnostics, collect evidence and escalate to senior technician/network admin.

FAQ 4 - Settings - Accessibility

# How do I make my text cursor more visible?

User goal: Adjust text cursor settings to increase visibility.

Tool path tested: Settings - Accessibility - Text Cursor

Steps:
1. Open settings using Windows start navigation or using shortcut Win + I
2. Open "Accessibility"
3. Select "Text cursor"
4. Change desired settings e.g. enable cursor indicator, adjust cursor thickness, cursor blink rate.

Escalate - If display issues continue after changing settings, escalate to a senior technician.
