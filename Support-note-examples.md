# Ticket CVNP1606-w02-Example - Resolved

User states their Outlook icon is missing from their desktop.

Located the app using Windows search.
Confirmed the app was still installed and functional.
Right-clicked the Outlook icon, selected "pin to task-bar" and created a new desktop shortcut.
Advised used on how to open Outlook using the taskbar icon and verified it launched correctly.

Resolution - Desktop shortcut restored. Added taskbar icon for user ease of access.
Issue resolved. No further action needed.



# Ticket CVNP1606-W02-Example - Escalation

User states display cuts out and flickers.

Checked display settings and determined to be hardware issue.
Checked connection cables at both tower and back of monitor.
Issue determined to be faulty HDMI port on back of monitor.

Collect evidence, escalate to senior technician OR IT Hardware technician.
